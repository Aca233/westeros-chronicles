# 角色扮演重构实施状态

日期：2026-09-08。核心运行时重构已经接入默认玩法。本页是设计文档与当前代码之间的状态索引；源码仍是最终权威。

## 已接入默认运行时

- **唯一结果与原子提交**：严格判骰协议，成功/失败命令及世界意图分别选轨；缺失或无效协议不再猜测结果。
- **显式场景**：周目保存当前地点、内部场景和在场名单；提及、旧交互或同城不再自动等于在场。
- **认知与人物卷宗**：NPC 详情按玩家可见知识投影；隐藏记忆、确切身体/装备/位置和未获知死讯不进入普通卷宗。
- **社会账本**：请求、接受、拒绝、条件、承诺、披露、履约和违约带稳定人物 ID、受众、来源与期限保存；未了承诺进入提示词与行动栏。
- **通信与主动人物**：消息按送达日传播知识；NPC 议程和委派按期限进入待回应节点。委派需要受任者明确接受，结果会留下关系依据。
- **长期记忆**：详细记忆按重要性与近期性限额召回，其余形成短归档摘要；每名 NPC 每回合最多写入一条重要亲历记忆。
- **大量人物**：模型上下文只加载当前场景与相关人物；卷宗提供当前场景名单和全局检索，人物总量不直接扩大每回合提示词。
- **物品、据点与装备**：装备必须来自直接携带；卸装和替换要求明确合法去向；仓储按体积计算；远方清单不提供当前场景效果。
- **交易、修理与旅行成本**：买卖同时结算物品与银鹿并引用对方接受事件；修理要求可访问工具、材料费和耗时；启程按路线扣除银鹿，余额不足整次拒绝，长途跳时停在最早消息/承诺/议程节点。
- **治疗**：只有当前可访问且用途匹配的医疗实例能够治疗，成功结算后原子消耗；绷带、止血药和解毒剂不能互相冒充。
- **身份规则**：普通命令不能直接改头衔；授予、继承、撤销与争议走世界授权规则。婚姻必须引用此前公开、双方参与的婚约与接受事件。
- **检定与特质**：骰面 1/20 不自动决定成败；旧伤不会被轻伤覆盖；移除随机抗伤和泛化金币收益倍率；特质 ID 成为规则来源。
- **模型运行层**：规则解析与正文使用独立的温度、输出预算和提示词版本；隐藏推理不再拼入正文流或新存档；近期正文与实体切片均有限额。
- **上下文审计**：调试面板记录完整/轻量/省略人物 ID 及资产、事件、地点、排队事务计数；记忆摘要按受众与参与者分区，不扩大秘密可见范围。
- **UI/UX**：自由输入为主，建议只预填；支持 Ctrl/Cmd+Enter、取消与草稿保留；人物/地图/资产抽屉统一；死亡后提供人生回顾和未了事项。
- **开局身份**：自建人物可选择封地领主、家臣/侍从或流浪者；钱财、据点、载具、装备位置和开场处境随身份变化。

## 已从标准玩法撤下

- 逐行动选择强制骰或跳过骰子。
- 固定勇武/谋略/外交三选一建议模板。
- 普通物品无目标“使用”、一键百分比修理和无同意赠礼。
- 直接覆写关系数值、免费治疗 NPC、直接修改玩家头衔。
- 原作未来压力进入当前正文、普通玩家查看 NPC 全量私密状态、展示模型思考文本。
- 未真实结算的路线风险百分比；费用现已按银鹿真实结算，风险仍只显示定性等级。
- 400 点建角保留为明确标注的高级沙盒，不再作为标准人物选择入口。

## 兼容与边界

存档格式已升级到 v10；读取或导入 v9 时会保守补充场景、社会账本、通信与议程空状态，不从旧小说正文臆造秘密、承诺或在场者，也不删除旧存档。旧 `think`、直接治疗和直接关系命令只保留读取兼容，不再由默认 UI 与提示词生成。

完整经济、全局逐日 NPC AI、战棋、产业链、通用魔法树和自动继承已从当前产品范围移除。默认运行时只处理与玩家场景、通信、期限和委派相关的局部人物活动；`npc`/`memory` 模型档案保留扩展位，默认不增加额外调用。死亡页因此不会伪造继承人或瞬移资产。

# 全游戏机制审视与重做决策

日期：2026-09-07。产品方向：角色扮演。范围：当前玩法、全局 UI/UX、角色信息与面板、世界资料、规则结算，以及支撑长期游玩的模型和存档机制。用户允许对全部游戏内容提出重做、删除和新增。

状态：审视与重构决策已完成，核心运行时已于 2026-09-08 接入；实际范围与验证边界见 [实施状态](../IMPLEMENTATION_STATUS.md)。

## 1. 总判断

当前项目已经有扎实的世界资料、物品归属、地图和事务基础，但角色扮演的闭环仍偏薄。部分系统能够记录结果，却缺少形成结果的过程：可以改婚姻、头衔、金币、伤势，却未必有足够的意愿、资格、交易、治疗和冲突规则支撑这些变化。

因此下一版应围绕 **场景、人物关系、认知、义务、处境与后果** 重组产品。人物有理由接受或拒绝，玩家有值得承担的选择，世界变化有证据与代价。地图、装备、金钱和六项能力为这个过程提供约束与机会。

不要求所有玩家成为领主，不要求所有局面变成权谋，不要求每拍都有危机。侍从、游侠、贵族、学士与统治者可以共享同一个世界，其行动权限与烦恼来自身份。

## 3. 最重要的产品决策

### 保留的根基

- 一个共享周目世界、稳定实体 ID、静态基线与动态覆盖。
- 规则验证、唯一结果、原子提交、取消、恢复和存档隔离。
- 原作身份与历史关系；自建角色可以嵌入同一世界。
- 六个能力领域，但重做量尺、成长与修正来源。
- 物品唯一归属、真实距离、有限认知、可追溯事件。
- 自由输入与正文中的人物/地点链接。

### 默认玩法中删除或移出的内容

- 每次行动手动挑“强制骰/不骰”的结果控制；改为周目规则设置与骰子显示偏好。
- 400 点特质商店作为建角主入口；移入明确的高级沙盒编辑器。
- “贪婪就让所有入账凭空变多”、勇敢随机抵消伤害等无具体因果的被动规则。
- 每挡一下固定掉 5 耐久、点击就修 25 耐久的维护循环。
- 普通物品的多层品质/稀有度/声望数字，以及玩家必须逐件拆分整理的默认操作。
- 尚未真实结算却以百分比展示的路线风险与无单位费用；补闭环前改为定性预估。
- 默认游戏中的原作未来时间线与 NPC 全量内心记忆；移到有清晰边界的资料/调试入口。
- 每拍长篇、固定三条属性路线、人人都能下“御令”的统一叙事模板。

删除的是上述规则与默认交互，不是未经迁移直接删除源资料、存档字段或历史记录。美术、地图和导入资源可以保留在可选展示与内容库。

### 必须重做

开局与身份、检定与能力、创伤治疗、交易和资源、关系与婚姻、头衔与授权、旅行、原作事件触发、人物卷宗和死亡后流程。详见蓝图，不只更换名称。

### 必须新增的最小核心

场景与在场证据；诉求/拒绝/有条件同意；承诺与截止日期；个人认知与信息传播；有来源的关系变化；冲突中的非死亡失败；按模拟时间处理的议程；人物日志与可追溯后果。

这些共用少量事件与状态基础，不各自建立一套庞大的管理界面。暂不新增完整产业链、全球人口经济、所有 NPC 的逐日 AI、随机刷怪、通用法术职业树或自动繁衍模拟。

## 4. 已确认的关键风险

| 问题 | 本次证据与解释 |
|---|---|
| 新轻伤覆盖旧重伤 | 函数实验从 heavy 变成 minor，同时保留“旧重伤”文本，身体数值和经历矛盾 |
| 退款被特质放大 | 贪婪角色从 100 扣 100 再加 100 后变为 120；证明结算无法区分退款与收益，不等于已证明存在完整商店套利链 |
| 玩家新特质不进入规则 ID | `ADD_TRAIT brave` 后 traits 有值而 traitIds 为空；显示与加成来源分裂 |
| 30—100 属性值的检定效用相同 | 不计其他修正时，30/60/100 对 DC14 均为 85%；成长显示和收益脱节 |
| 头衔授权链未闭合 | 转换器能把不持有头衔者的自封转成 holder/controller 变更；上游处理器直接调用它，双方注释对授权位置的认知还互相错位 |
| 物品“使用”与疗效分离 | 绷带使用消耗实例，底层返回物品状态和日志；没有绑定伤势目标、药效与用量的一体化治疗合同 |
| 路线成本/风险主要用于寻路与展示 | 已搜索消费者，totalCost/totalRisk 没有进入旅行资源扣除或遭遇结算 |
| 人物记忆界面绕过认知过滤 | NPC 卷宗复制全量 memories，经历页直接渲染；世界事件过滤不能保护这条独立链 |

上一轮发现的成败轨回退、世界意图未分轨、提及等于在场、未来压力进入正文、知识投影为空仍然有效，纳入本次优先修复。

## 5. 如何判断新版真的更好玩

玩家应能在不翻规则的情况下回答：我现在面对谁、想得到什么、手里有什么筹码、对方为何不答应、继续会付出什么、先前的选择如何影响现在。

用三种完整人生处境验证：弱势人物在求职/效忠与个人底线间选择；有既有关系的人物处理私诺与公开职责的冲突；统治者通过使者、家臣和资源处理请求而不逐个整理仓库。三个视角必须共用事件、关系、时间和资源规则。

本次已完成源码与调用链审视、局部函数复现和相关自动测试；没有把无真实模型的测试当作中文长局文笔或真实玩家体验证明。发布前仍须按验收文档完成端到端试玩。

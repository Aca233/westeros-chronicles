# 新版玩法与规则蓝图

状态：重做后的目标设计，不代表运行时已实现。数值均为待校准初值；方向性删除和权威边界是本次明确裁决。

## 1. 产品形态与共同循环

定位为有持续世界的单人角色扮演：玩家以一个人的身体、身份、关系和认知面对局势。统治领地是某些身份能做的事情，不能作为所有人物的默认玩法。

微循环是一拍交互：观察或表达 → 对方/环境回应 → 选择承担什么 → 结果被记住。

中循环是一个场景或一件事务：提出诉求 → 寻找信息/筹码 → 改变态势 → 达成、拒绝、失败、暂缓或离场。

长循环是一段人生：建立关系与身份 → 承诺互相冲突 → 经历造成转变 → 得到或失去机会 → 回顾尚未完成的愿望。

玩家随时可自行提出目标。角色没有必须追逐的统一分数、权力榜或任务清空率。故事可以以退休、离开、完成愿望、死亡等方式形成阶段结局；不把“成为国王”强加给所有人。

## 2. 共用状态基础：少建系统，多形成闭环

| 基础对象 | 保存什么 | 服务哪些玩法 |
|---|---|---|
| Scene | 时间、在场证据、可达空间、当前焦点、待回应事项 | 对话、调查、战斗、开场 |
| Character | 身份、能力等级、稳定性格、身体、角色目标 | 所有扮演 |
| Knowledge | 某人通过什么来源知道/相信/怀疑什么 | 秘密、调查、名声、信件 |
| Relationship | 方向性态度、共同经历与未偿义务 | 亲情、友谊、效忠、爱情、仇恨 |
| Obligation | 承诺、契约、职责、期限与履行条件 | 借款、婚约、家臣命令、誓言 |
| Conflict | 双方诉求、资源、态势、可接受结果、退出条件 | 决斗、争执、追捕、政治争端 |
| Project | 目标、责任人、依赖、时间、成本、下一次决策 | 调查、训练、旅行任务、局部战役 |
| ResourceTransaction | 来源、去向、数量/单位、条件与依赖组 | 金钱、物品、医疗、后勤 |
| Event | 原因、结果、主体、时间、受众、来源 | 统一账本与所有投影 |

共用基础不代表把所有玩法变成同一种进度条。调查的线索证明关系与战争的兵力态势仍有各自 schema；Project 只提供责任、期限、依赖与中断框架。

## 3. 建角：先建立一个可以生活的人

默认流程改成五步：

1. 选择现成人物，或选自建人物的社会位置：家族成员、侍从/武人、知识与服务职业、漂泊者、已有合法权利的统治者。
2. 选择真实开局地点、来历和当前依靠。身份决定初始可用权限，不等于强制职业路线。
3. 选择少量形成能力的经历，以及 2—3 项性格倾向。经历可以提供师承、旧债、关系或技能，不都折算成加点。
4. 确认一个当前愿望、一件在意的人或事、一个可选底线。玩家可以留空、修改或在游戏中发现新的目标。
5. 查看开局事实卡：我是谁、我知道什么、谁认识我、我有什么、欠谁什么、眼前发生了什么。

精确加点、任意年龄、全部特质、改写家族和领地归属留在“高级世界编辑”，明确这是编辑世界。默认不向用户列出数百个可买卖的人格词条。

现实约束与玩法自由并存：采用著名家族姓名不会自动成为其血亲；自建家族也能有纹章与传统，但领土必须来自已验证授封、开局插入合同或明确替换。没有这条合同，就以寄居、受雇、旁支等合法处境开始，不编造一整座不存在于地图和账本的城堡。

现成人物保留历史关系与权利，玩家决定此后如何行动。默认固定世界起点，更多年代开局必须有对应基线与内容验证，再开放选择。

## 4. 输入、行动单位与节奏

输入框改可扩展多行，支持“说什么”和“做什么”混合表达；不要要求用户学习命令语言。程序保留原输入，并生成简短行动解释供必要时纠正。

一次提交最多推进到下一个真正需要玩家决定的节点。玩家写“先问他，再根据回答决定要不要送钱”，只能先问，不能模型替其决定送钱。玩家明确提出连续无争议动作，可合并处理。

按后果分三种入口：

- 纯界面操作，如看地图/卷宗、调整阅读设置，不推进世界时间，不调用模型。
- 确定性的世界小动作，如在安全私室换常服，程序直接验证并以小事件记录；必要时在下一段正文简要带过，不强迫写一章。
- 需要他人回应或存在真实风险的行动，进入完整规则与叙事流程。

小动作也可能有成本：城墙下换重甲会占用时间和暴露风险，不能借“整理装备”绕开战斗。实现上仍使用同一事务机制，可用没有小说正文的 action event；不要创建与世界账本无关的第二条状态通道。

建议行动以 2—4 条为常见数量，按目标/方法/代价区分。危险快捷键默认先把意图填入可编辑区域；愿意一键行动的用户可开启明确偏好。没有失败草稿被立即清空的问题。

## 5. 能力与检定：删除虚假的精度

保留六个能力领域。训练和专业资格用少量标签补充，例如外科经验、骑术、熟悉某地、识读某种文字；专业标签提供资格或可用方法，不建立无限小技能列表。

默认界面把能力显示为 0—5 的有效等级与文字描述：无训练、初识、熟练、老练、专家、卓绝。AGOT 原始 0—100 数值保存在来源层，映射到有效等级；超出最高档的差异用有根据的专长表达，不继续显示无收益的可升级数字。

一组用于首轮平衡测试的映射是 0—4/5—9/10—14/15—19/20—29/30+ 对应等级 0—5；迁移需要按完整导入分布审查，不直接默认它已经公平。

检定流程固定：

1. 验证是否可能、是否有资格与工具、目标是否明确。
2. 确认存在值得裁定的不确定性。无阻力或条件充分直接结算；无法做到则说明可观察障碍。
3. 创建风险合同：目标、方法、成功范围、失败范围、共同成本、可见风险、是否允许代价达成。
4. 汇总不重复的能力与情境来源；程序决定 DC 并记录每项依据。
5. 仅对该合同进行一次随机采样，选定结果并锁定。

可沿用 D20 实现。首轮测试候选公式为 `D20 + (2 × 能力等级 - 4) + 情境修正`，情境修正先限在 -4 到 +4，候选 DC 为 8/12/16/20。它是便于平衡验证的明确起点，不能未经分布测试就称为最终平衡。移除自然 1/20 无条件自动成败；没有不确定性就不骰。

同一来源只能进入一次：熟练剑术已经体现在勇武等级，就不能同时以“勇武高、剑术熟练、战士教育”重复加三次。装备有功能门槛或实质优势才修正；礼服只有被对方与场合认可时可能有用。

结果展示区分“达成”“达成但承担已定义代价”“未达成并产生已定义后果”“前置受阻”。首版不必增加四种掷骰区间：成功轨本身可包含代价，失败轨可改变局面，受阻无骰。任何需要玩家选择的新代价应停下来提出条件，不能检定完自动替玩家付出未授权重大牺牲。

标准周目移除逐行动 force/narrative 开关。骰子动画、公式显示可关；裁定仍照规则运行。另设明确的共创沙盒模式，允许结果协商与编辑，但不能静默复用标准模式的错误回退。

## 6. 人格、成长与内在压力

人格回答“倾向注意什么、在意什么、哪些选择更难受”，不直接制造金钱、免疫刀伤或强迫角色台词。NPC 的人格影响可谈判范围与表达；玩家的性格允许违背，世界根据实际言行重新理解他。

成长由经历门槛触发：有时间投入、有指导或真实困难、得到具体反馈，再形成训练进展；完成一个阶段才改变有效等级或专业资格。重复无风险动作不能无限成长。普通聊天、换装、反复受轻伤均不刷成长。

暂不新增通用经验值条与庞大技能树。先做有来源的训练 Project 和少量关键经历里程碑。

内在压力采用“当前负担”而非每句不符合特质就扣精神值：丧亲、长期失眠、背弃自己明确认可的誓言、重大羞辱可以形成一项负担，有持续时间、影响与缓解渠道。玩家不因模型认定“不够勇敢”被强制发疯或改变人格。

先天、疾病、教育、声誉与职位分开维护。所有新获得特质通过规范 ID 和统一投影，系统状态与显示文本不能各走一条链。

## 7. NPC、伙伴和关系

每个活跃 NPC 保存一小张运行卡：稳定价值、当前诉求、可承受代价、自己的认知、与玩家的关系依据、未偿义务、当前情绪。名声与真实动机可不同，但动机不能每回合随机生成。

保留六种关系含义，初期只更新本次事件相关维度。内部可沿用数值以便调试，游戏视图展示“曾为你作证”“因失约不再轻信”“敬畏你的地位”这类有来源的描述。恐惧不是忠诚，吸引不是同意，尊敬不等于服从。

更新规则应包含事件类型、影响上限、是否重复、行为成本与既有关系。普通赠礼不会无限刷关系；相同低成本礼物在短期内影响递减，明显利用对方时甚至产生反感，但反感要有事件依据。

伙伴有任务、职责与去留，不默认接受所有命令。同行前有明确同意/雇佣/职责依据；指派事务记录目标、权限、资源和汇报渠道。玩家看不到远方伙伴的实时内心与精确进度，只能通过消息了解。

没有必要每回合为全部人物运行模型。当前场景完整模拟，相关伙伴/议程按时点推进，其他人物保持惰性基线；被重要事件激活时再展开。

## 8. 社交、誓言与婚姻

交谈的规则对象是诉求与筹码：请求对象、希望对方做什么、给出的证据/理由、交换条件、公开或私下场合、潜在损失。说服检定可以让对方认真听、接受小让步或给出机会，不能无视终身利益与人格红线。

请求可以被直接拒绝且不扣好感。对方未承诺前不会生成义务；“我会考虑”“可以谈谈”与“我答应明早归还”具有不同事件语义。

承诺包含承诺者、受益人、事项、成立条件、期限、见证人、可接受履约证据、宽限与失约判断。日程检查不能把因道路封锁而无法赴约与蓄意背弃混成同一结果。社会后果通过实际知情者传播。

亲密关系是可选的人物内容，走相处、信任、表达、回应和边界；不设置“吸引到 80 必定成功”的阈值。人物能拒绝，玩家也能拒绝。

婚姻拆成表达意向、协商/家族要求、婚约、完成相应制度行为，再产生婚姻状态事件。世界观中的政治强迫可作为明确剧情冲突，但不意味着模型可以擅自让玩家同意。离婚、废除与分居按相应制度与当事人处境处理。

本期保留亲属基线与已确认的家庭事件，不做全世界自动生育和婚配算法。若以后加入新生与代际续玩，另建年龄、家系、监护和时间跨度合同。

## 9. 秘密、调查、书信与名声

世界真相、某人说的话、某人相信的话各自记录。发现丢失不等于知道窃贼；NPC 作证不等于案件已经查明；公开发生也不等于所有人立刻知晓。

一条线索至少有来源、获取方式、可支持的命题、无法证明的部分、是否可能被伪造及当前持有人。调查围绕验证线索和选择方法，而不是连续多次“学识检定直到模型透露答案”。

同条件重复尝试复用已有结果。新的证据、方法、协助、地点或足够时间变化才允许重新裁定。失败可以暴露调查意图、消耗时机、留下不完整证据；不要为了逼迫主线总在最后一条线索处封死。

通信是 Project 的小型实现：发件人、收件人、载体、渠道、出发与预计到达、异常条件。信件送出不等于到达，读信不等于相信。可以截获、伪造、转述，但必须有相应行动过程与后果。

名声由人群中的已传播事件形成，至少区分地点/组织/重要关系圈。某地的勇名不会自动变成所有人的好感；丑闻也不全地图瞬时生效。先做少量圈层和明确传播，不建全球逐人谣言扩散模拟。

## 10. 法律、权利与越权行为

程序明确区分：物理可行性、使用/命令授权、社会合法性、被发现的后果。

同在一个仓库可以有机会偷拿物品，但不代表获准合法取用。没有授封权的人可以宣布自己为王，系统记录宣称与旁人反应；不能因此直接改所有头衔持有人。

为合法结果要求 `AuthorityEvidence`：现有权利、受权范围、机构/人物授权事件或有效判决。非法手段走相应 conflict/crime 事件路径，再按实际胜负改变控制；法理是否被承认后续解决。

首版实现权限、控诉、证据、拘押/释放、赎金或赔偿几个关键环节，不构建穷尽所有原作法系的法院模拟。社会地位影响谁能要求解释、谁有执行能力，但弱势人物始终有可尝试的行动，不被界面彻底封死。

## 11. 冲突与战斗

共用冲突状态保存：各方目标、当前态势、行动距离/位置、重要资源、已知风险、退出条件。它可以表达决斗、追逐、抓捕、暴力恐吓；纯粹意见不合不强制变成战斗。

一拍选择战术意图，例如逼退、掩护、夺路、制服、击杀或谈条件。详细到意图和关键局势，不逐帧记录招架角度。敌方有自己的目标，受重伤或得不偿失时可以撤退、投降或求援，不必战至死亡。

结果由机会、装备功能、训练、人数、地形与前置态势决定。致命后果需要已存在的致命风险和能够造成它的行动。高骰不会凭空制造敌人，低骰也不会让普通寒暄招致斩首。

默认增加非死亡结果：被缴械、受伤逃脱、受俘、欠下赔偿、失去面见资格、暴露身份、目标逃离。后果必须与本次冲突有关，并形成下一段角色处境。

玩家与 NPC 共用伤害/失能/死亡规则；不要玩家要计算护甲，NPC 却只凭 KILL_CHARACTER 字符串死亡。仲裁模型只能提案，程序在同一冲突合同中裁定。

## 12. 创伤、治疗与生存

保留四个身体区域作为显示与影响汇总。底层改独立 Wound：部位、原因、严重度、发生时间、是否稳定、活动限制、愈合条件。新增轻伤不能覆盖旧重伤；治疗不能随便清除全部历史。

严重度与活动影响分开：轻微手伤可能不影响走路，却影响精细操作。出血、中毒、感染是有来源、进程与处置条件的状态；不再只用永久开关。

治疗动作绑定施术者、目标伤口、工具/材料、操作方式和时间。止血、稳定、减轻症状、长期愈合是不同结果。用一卷绷带可以支持止血处理，不能瞬间恢复断肢。没有明确用途的药品“使用”按钮删除。

护甲按实际覆盖部位与攻击类型限制伤势，不以人格随机免伤。装甲遭受足以破坏功能的事件后才改变状态：完好 → 受损 → 不可用。普通接触不每次掉固定耐久；必要维修需要合适人员/工具/时间/支付。

日常饮食、休息和御寒默认由正常生活条件覆盖。只有赶路、受伤、资源匮乏、被困等场景才激活困乏、饥寒或缺补给状态。不增加强迫每回合点吃喝的生存条。

死亡是统一规则结果，可以结束人物线；让玩家看见死因、重要关系、遗留事务与世界后续。玩家可以读档探索不同选择。接替另一人物延续世界是后续独立功能，需重新计算知识视角与控制权。

## 13. 物品：保留意义，减少搬运

后续专项：[据点、仓库与装备](storage-equipment.md) 进一步明确取消泛化据点、区分住处/储藏/使用权，统一 UI 与世界动作规划；装备区分穿戴、武器入鞘/持用和随身工具取用。该专项是本节的细化合同。

玩家默认只面对三类组织：当前装束、随行物资、可访问储藏。实际层位、双手冲突、体积与唯一归属保留在程序中，界面以可行装束和装载方案减少点击。

常服、出行、防寒、战斗可以保存为预设。预设只是装备目标，不生成物品；出发时缺盾就显示缺盾，不从远方库房召唤。换装按所处场景决定耗时与风险。

普通成堆物品自动合并和转移，保持总量；带独立历史、证据或身份意义的物品不能随便合并。保留玩家按需拆分赠予的能力，不把拆堆作为每次操作必经流程。

默认物品只显示功能、可用状态、携带情况、来源/纪念意义。材质和工艺只有产生具体效果时突出，稀有度与声望留资料详情。删掉“稀有所以一定更强”的默认数值阶梯。

信物、印章、钥匙、信件、证物与有故事的宝剑是核心角色扮演道具。它们可以授权、作证、质押、被伪造、引发记忆，功能来自合同与具体经历。把物品标为传家宝形成个人/家族意义，不能一键提高战斗属性。

赠礼分提出、回应和交割；受赠者可以拒绝，或接受物品却拒绝请求。贿赂与赠礼的社会含义由场合和认知决定。盗窃依同一结果轨改变保管与控制，所有者何时得知另行传播。

## 14. 金钱、交易与生活资源

废除对所有正向入账统一乘倍率。建立交易类型：收入、付款、退款、转账、借款、偿债、扣押、赎金；有明确来源/去向、金额和单位，退款引用原交易。

不在初版发明复杂货币市场。保留金龙/银鹿表现，规则配置明确计价与兑换单位；当前资料无可靠价格的服务先用经过策划审核的报价模板。不能模型任意在不同回合改变同一笔约定金额。

交易包含交易对手、对象、数量、价格、时间与地点条件；双方交割为同一原子组，余额不足不能只拿到物品。谈判改变报价，不能在成交后因贪婪让对方无故多付。

玩家的随身钱与所控制组织的资源分开。领主的私人零钱不等于整个北境财政；无正式授权不能花用公库。首版用已命名的预算/物资承诺，而不是精细到每一座庄园的现金流。

与角色扮演直接相关的资源先做：差旅、食宿、雇佣、医疗、礼物、债务、赎金与需要承担的义务。完整税收、建筑、人口、商品供需和生产链延后。

## 15. 头衔、组织、继承与战役

称谓是事实的显示，不是任意字符串修改权。区分正式职位、头衔权利、自称、外界称呼与实际控制。新授封必须验证授予者的权利和对象，接纳职位可能附带誓言与职责。

组织关系先围绕谁向谁负责、承担什么、有什么权限、失职有什么后果。玩家以统治者身份主要通过家臣/使者/封臣行动；普通人物也可能成为其中的成员或受影响者。不是每个阵营都显示一个通用好感条。

继承在死亡或明确触发事件后形成案件：遗产清单、候选资格、指定/制度依据、保管状态、争议者、何人承认。合法继承不自动获得实际控制；占领者也未必有合法权利。首版覆盖已策划的主要规则与案例，未知复杂继承保守进入争议流程，不能凭模型一句“依法继承”改完地图。

局部战役只为有指挥权的相关角色激活：目标、可支配兵力级别、指挥者、补给与路线、敌方已知实力、时点和退出条件。先允许布防、护送、突袭、围困、退兵与谈判等有限行动。

战争不能由一次军事骰直接“占领王国并和平结束”。先形成战役/谈判结果，再授权头衔和控制权变更。完整军团兵种、战略 AI 和领土涂色不是当前主线交付目标。

## 16. 地图、旅行与季节

地图首要呈现：当前位置、已知可去地点、想见的人或办的事、估计耗时、可知风险和未完成旅程。五级政治层与 3D 地标保留在按需层，地形细节不增加玩家管理负担。

一次旅行先确认交通方式、同行者、装载、成本和出发条件。允许步行、自己的坐骑/车辆、付费服务；界面可隐藏不可用模式，规则层仍需验证，不能只依赖按钮禁用。

路线给实际的报价与成本依据，按出发/途中/到达的合同扣除。风险先用来源和等级描述；只有实现了校准过的遭遇概率才显示精确百分比。安全路线也可能慢到错过约定，形成明确取舍。

世界时间推进到最早的决策节点：消息送达、承诺到期、道路障碍、必要补给、已定义的遭遇或终点。平静路段直接快进，不要求玩家重复“继续赶路”。遇到新重大风险先停下供玩家决定，避免自动替玩家深入。

日历负责日期，世界季节负责長夏/长冬状态，地方天气负责当前环境。路线计算读取规范状态而不是匹配中文“冬/寒”字样。玩法日期、地图耗时、伤口恢复和义务期限使用同一模拟时钟。

## 17. 原作压力、魔法与世界主动性

原作节点作为具有前置条件和可替代路径的内容模板。到期检查人物存活、位置、资源、动机和依赖；前置改变时延后、替代或取消。不能因某个相关人更换过物品就简单取消所有关联历史，也不能无视玩家行动照演原作。

世界事件发生与玩家获悉分开。普通游戏日志只呈现当前已知历史。原作资料库可独立打开并明确属于资料阅读，不自动写入角色知识或生成上下文。

魔法保留未知感但有边界：预兆不是已验证预言，梦境不直接等于命令，血统标签不自动解锁所有能力。只对明确相关人物/内容定义激活条件、代价、失败范围与可观察证据。不存在通用“模型说可以就可以”的法术接口。

龙使用特殊生物合同：独立身份、地点、与人的关系、可观察状态、行动意愿、骑乘资格与能力范围。初版只做相关篇章必须的少数交互；不做庞大驯养数值、繁殖或把龙塞入配饰槽的捷径。

世界主动性按事件与模拟时间调度，关闭游戏默认暂停。背景人物仅在与当前世界变化相关时处理，避免全天候为全大陆调用模型，也避免用户长时间等待生成时世界在现实时间里偷偷跑过截止日。

## 18. 信息界面、模型与存档

默认主界面聚焦正文、行动、当前位置/时间、紧迫事项。人物卷宗先展示已知身份、共同经历、态度依据与当前可观察状态；隐藏秘密、未经观察的精确数值和后台推理。

人物日志分未竟之事、重要关系、已知线索与往事，所有条目能回看来源。技术队列留到操作状态，不占据剧情任务列表。

保留两次默认模型调用与程序状态权威；简单无争议世界操作可零模型，复杂私有 NPC 决策按需额外调用。未知实体和新场景细节可以提案注册，重要后果仍须验证，不能以“自由度”绕过账本。

原子提交扩展到场景、社会、认知、资源与正文。流式文本只是预览；失败、取消、断网不扣资源、不失去草稿、不重骰。UI 允许阅读旧正文和查询非冲突资料，不必全页面冻结。

默认保留撤回与分支探索，不用“沉浸感”强制铁人。挑战模式可以限制主动回退，但只能在明确选择的周目启用，仍应修复技术失败；客户端存档可被编辑，不虚称防作弊或公平竞技。

## 19. 三段证明系统有效的玩法

### 弱势人物：进不了门

自建侍从带着一封介绍信来到城堡，请求见总管。信是真实道具，但不保证开门。守卫可因职责拒绝；玩家可以说明来意、找担保、等待或另寻工作，也可冒险行贿/潜入。

承认介绍信来源后获得面见机会；被怀疑则形成待验证线索。没有临空封臣，没有立刻改变爵位。达成后的收益是工作、栖身处、联系人与新职责。

### 有关系的人物：私诺撞上公事

玩家答应替家人暂时保密，同时接到公开职责要求说明情况。NPC 只知道各自渠道里的信息。玩家可履约、坦白、协商延期、寻求证据或违背承诺，各自产生具体关系后果。

几天后的重逢会召回实际发生的履约和解释，而不是简单重复“他很信任你”。调查、书信、名声与时间在同一个案例里联动。

### 统治者：一笔钱只能解决一件急事

家臣请求拨款修桥，另有人请求支付护送费用；组织预算不足以同时承担。玩家可委派调查、谈分期、寻求资助、动用自己的钱或推迟其中一项。

项目有责任人、期限和报告渠道。桥梁影响旅程，护送影响人物到达和另一项承诺。没有一条“管理大成功”凭空把钱变成两倍，也不要求玩家逐件搬运所有木材。

三段都应能出现可接受的失败、主动退出和后续机会。若只能照固定选项走通，说明规则仍然只服务模板而没有支持角色扮演。

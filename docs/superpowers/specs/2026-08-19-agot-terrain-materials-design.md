# AGOT 地形材质与 CK3 式近景切换设计

日期：2026-08-19
状态：待用户复核

## 1. 目标

在现有离线维斯特洛地图上加入来自本地 CK3 与 AGOT 游戏文件的真实地表材质，使近景能够显示草地、农田、泥地、沼泽、岩石、雪地、沙地等 AGOT 已配置的地形贴图，同时保留现有远景地图图片。

地图必须采用 CK3 式分段表现：远景只显示平面地图图片，进入近景后直接切换为地形材质，不在两个底图之间进行半透明交叉融合。桌面滚轮缩放必须在缩放过程中同步改变倾角，不能等待缩放停止后才补做倾斜。

第一版只处理地表材质，不加入三维树木、建筑、植被模型或独立水面渲染器。

## 2. 约束

- 地形素材只允许在开发期从本机 CK3 与 AGOT 目录离线提取。
- 浏览器运行时只读取项目内生成好的静态瓦片，不读取 Steam、Workshop、CK3 或 AGOT 目录，也不访问网络。
- AGOT 模组素材优先于 CK3 本体素材；模组缺失的被引用材质允许从 CK3 本体补齐。
- 生成结果必须可审计、可重复，清单不得保存本机绝对路径。
- 公开地图层级仍为战略区域、公国、伯爵领；地形材质不改变现有地点、寻路和政治投影规则。
- 测试版不要求兼容旧地图清单或旧存档中的地图缓存字段。
- 界面和生成资料不得包含 Emoji。

## 3. 已确认的本地素材

AGOT 模组提供以下地形合成资料：

- `gfx/map/terrain/detail_index.tga`：9216 × 6144 RGBA 材质索引图。
- `gfx/map/terrain/detail_intensity.tga`：9216 × 6144 RGBA 材质权重图。
- `gfx/map/terrain/materials.settings`：有序材质声明、材质 ID、Diffuse 贴图与铺设参数。
- `gfx/map/terrain/**/*_diffuse.dds`：草地、山地、雪地、沙地、沼泽、农田等地表颜色材质。
- `gfx/map/terrain/flat_maps/flatmap.dds`：现有远景平面地图图片。
- `map_data/heightmap.png`：现有 DEM 的原始高度图。

Normal 与 Properties 贴图保留为未来增强输入。第一版地表颜色由 Diffuse 材质烘焙，坡面明暗继续由现有 DEM 三维地形与 hillshade 提供，避免在离线颜色中固定一个与相机无关的光照方向。

## 4. 方案选择

### 4.1 采用：离线材质烘焙

离线导入器重建 AGOT 的四通道材质混合，将结果输出为普通 WebP 栅格瓦片。MapLibre 只负责显示烘焙结果和现有 DEM。

采用理由：

- 能保留 AGOT 原始材质分布，而不是按纬度或省份重新猜测地貌。
- 浏览器无需维护纹理数组、自定义着色器或第二套三维渲染器。
- 可沿用现有 MapLibre 瓦片、缓存、故障隔离和离线边界。
- 对普通集成显卡和关闭高级图形功能的设备更稳定。

### 4.2 不采用：程序化生物群系重建

仅根据高度、纬度和省份类型分配材质会丢失 AGOT 绘制的雪线、荒地、海岸和特殊区域，不能满足还原目标。

### 4.3 暂不采用：浏览器实时材质混合

运行时上传索引图、权重图和全部材质并用自定义 WebGL 图层混合，能保留更高频细节，但需要独立纹理管理、着色器、显存预算和 MapLibre 深度协调。第一版收益不足以抵消兼容性风险。

## 5. 离线导入架构

### 5.1 新模块边界

地形材质导入拆为四个职责单一的模块：

1. `material_catalog`：解析 `materials.settings`，保持声明顺序，解析材质 ID、Diffuse 路径和 `tile_factor`。
2. `material_sources`：按“AGOT 覆盖 CK3 本体”的优先级解析并解码 DDS，不把绝对路径写入输出。
3. `material_compositor`：根据索引图和权重图进行四通道混合，使用全图坐标计算重复 UV，保证瓦片边界连续。
4. `material_tiles`：按现有维斯特洛裁剪范围生成瓦片、原子发布目录并返回审计报告。

现有 `cli.py` 负责组织上述阶段，不直接承担材质解析和像素混合逻辑。

### 5.2 材质目录解析

- `materials.settings` 中有效材质块的声明顺序定义索引映射。
- 注释掉的动态材质不进入索引。
- 每个有效材质必须解析到唯一 ID 和可读取的 Diffuse DDS。
- 相对路径先在 AGOT 地形目录解析，缺失时再在 CK3 本体地形目录解析。
- `tile_factor` 缺省时使用游戏地形设置中的默认值；若源文件没有可解析默认值，导入器使用显式、受测试的项目默认值并记录审计警告。
- 重复 ID、越界索引、缺失必需 Diffuse 或不支持的 DDS 格式必须使真实导入失败，不能静默换成随机颜色。

### 5.3 四通道混合

对于地图上的每个输出像素：

1. 从 `detail_index.tga` 的 RGBA 通道读取最多四个材质索引。
2. 从 `detail_intensity.tga` 对应 RGBA 通道读取四个权重。
3. 将非零权重归一化；权重总和为零时使用第一个有效材质作为确定性回退。
4. 根据每个材质的 `tile_factor` 和原始全图坐标计算循环 UV。
5. 以归一化权重混合四张 Diffuse 颜色。
6. 颜色处理在统一线性色彩空间中完成，输出前转回 sRGB，避免混合结果发灰。

采样必须锚定原始全图坐标，不能按单张瓦片重新从零开始铺贴，否则会在瓦片边缘形成接缝。

### 5.4 输出

新增静态目录：

```text
public/assets/agot-map/material-terrain/{z}/{x}/{y}.webp
```

生成级别为 `z0–z5`，瓦片尺寸继续使用清单中的 512 像素。WebP 使用固定质量、固定编码参数和稳定遍历顺序，确保相同源文件产生相同哈希。

地图清单升级到版本 3，并新增：

- `paths.materialTerrain`
- `counts.materialTerrainTiles`
- 地形材质所用源文件的内容哈希

清单只记录项目内 URL、Workshop ID 和内容哈希，不记录 CK3 或 AGOT 的绝对路径。

### 5.5 原子发布

材质瓦片先写入暂存目录，完成数量、路径、尺寸和解码审计后再替换正式目录。任一材质缺失、合成失败或发布失败时保留上一套完整输出，不留下半成品。

## 6. 运行时地图架构

### 6.1 双底图来源

MapLibre 样式包含两个独立栅格来源：

- `agot-flatmap`：现有 `flatmap.dds` 生成的远景瓦片。
- `agot-material-terrain`：新生成的近景地形材质瓦片。

两者使用独立栅格图层。政治填色、边界、标签、人物、路线、资产和地点继续位于底图之上。

### 6.2 硬切换，不交叉融合

底图切换与三维近景状态共用迟滞逻辑：

- 放大到 `zoom >= 3.25` 时请求进入近景。
- 拉远到 `zoom < 3.05` 时退出近景。
- `3.05–3.25` 之间保持上一次状态，防止滚轮停在阈值附近时反复闪烁。

两张底图的透明度只允许为 `0` 或 `1`，不得使用随 zoom 插值的半透明值。切换流程为：

1. 远景状态下保持 flatmap 完全可见，并让近景材质源准备当前视野瓦片。
2. 当前视野所需近景瓦片可用后，将近景层设为完全不透明。
3. 同一渲染周期关闭远景层；近景 RGB 瓦片完全覆盖远景，不发生混色。
4. 拉远时直接恢复远景层并关闭近景层。

若 MapLibre 无法在零透明度图层上预取瓦片，运行时允许保持近景层可见且透明度为零来触发加载，但任何可见帧仍只能有一个不透明底图。

### 6.3 地图模式

- 地形模式：完整显示近景材质和 DEM 地貌。
- 政治模式：在当前底图上覆盖现有半透明政治颜色，不替换底图。
- 人物、旅行、资产模式：通过现有模式控制降低底图亮度或饱和度，功能标记保持最高视觉优先级。

切换地图模式不得改变远近景状态，也不得重新生成栅格源。

### 6.4 三维回退

近景材质与三维 DEM 分开降级：

- DEM 失败但材质瓦片可用：继续显示俯视近景材质。
- 近景材质失败但 DEM 可用：保留远景 flatmap，并允许现有三维表面继续工作。
- 两者都失败：维持现有二维 flatmap。

任何地形故障都不能阻断正文、人物卷宗、地图搜索或旅行系统。

## 7. CK3 式桌面镜头

### 7.1 当前问题

MapLibre 的 `setPitch()` 会通过相机跳转更新状态。在原生滚轮动画仍运行时反复调用会打断缩放，因此现有实现只在 `zoomend` 后应用推荐倾角，造成“停止缩放后才突然倾斜”。

### 7.2 统一滚轮镜头控制器

桌面端禁用 MapLibre 原生滚轮缩放，新增受控滚轮镜头：

1. 监听地图画布的 `wheel`，标准化像素、行和页三种 `deltaMode`。
2. 累积并限制目标 zoom 到地图允许范围。
3. 以指针所在经纬度作为 `around` 锚点。
4. 根据目标 zoom、地图模式和俯视锁定状态计算目标 pitch。
5. 在同一次 `easeTo` 中提交 `zoom + pitch + around`。
6. 连续滚轮输入更新同一个目标，新的动画从当前相机状态平滑接续。

这样 pitch 会随 zoom 动画连续变化，不再由 `zoomend` 追加。

地点搜索、语义双击缩放、归北也继续在单次相机调用中携带目标 pitch。地形控制器在连续 zoom 阶段只负责 DEM 挂载和底图状态，不再写相机倾角。

### 7.3 触屏

触屏双指缩放保留 MapLibre 原生手势，避免自定义手势造成中心漂移。手势期间不强制写 pitch，`zoomend` 后用短动画校准到推荐倾角。该行为是已确认的第一版范围。

### 7.4 辅助设置

- “俯视”开启时统一镜头控制器始终计算 `pitch = 0`，近景材质仍可显示。
- “归北”只把 bearing 设为 0，并保留当前 zoom 对应的推荐 pitch。
- `prefers-reduced-motion` 下相机仍同时更新 zoom 和 pitch，但动画持续时间为 0。

## 8. 状态与职责

新增独立的近景底图控制器，状态包括：

- 当前是远景还是近景。
- 当前视野近景瓦片是否准备完成。
- 近景材质源是否已永久降级。
- 上一次迟滞状态。

它不拥有地图模式、选中地点或相机位置。地图模式仍由 `mapUiStore` 管理；相机位置仍由 MapLibre 和现有 viewport 持久化管理；DEM 能力仍由地形控制器管理。

滚轮镜头控制器只接收相机适配器、推荐 pitch 函数和 reduced-motion 状态，不直接操作图层或业务状态。

## 9. 测试与审计

### 9.1 导入测试

- 解析最小 `materials.settings` fixture，并验证声明顺序和覆盖优先级。
- 使用四种纯色材质验证 RGBA 索引与权重混合结果。
- 验证权重归一化、零权重回退和 sRGB/线性转换。
- 验证全图坐标采样在相邻瓦片边界连续。
- 验证缺失材质、重复 ID、越界索引和不支持 DDS 会失败。
- 验证同一输入两次输出的文件列表与哈希一致。
- 验证发布失败保留旧输出。

### 9.2 运行时测试

- 清单版本 3 必须包含近景材质路径和数量。
- 迟滞区间保持上次底图状态。
- 任意可见状态只有 flatmap 或 material terrain 之一为不透明。
- 近景瓦片准备前保持 flatmap；准备后原子切换。
- 材质源失败时保持 flatmap，且不设置整个地图初始化失败。
- 五种地图模式共用底图状态，政治覆盖与功能图层保持在底图上方。

### 9.3 相机测试

- 每次桌面滚轮目标同时包含 zoom 和 pitch。
- 连续滚轮更新目标而不是在 `zoomend` 追加 pitch。
- 指针锚点在缩放前后保持稳定。
- 俯视锁定、归北、减少动态效果和 zoom 边界行为正确。
- 触屏仍保留原生手势并在结束后校准倾角。

### 9.4 完整验证

完成后至少运行：

```bash
npm run verify:map
npm run build:code
git diff --check
```

地图审计还必须验证 `z0–z5` 材质瓦片数量、可解码性、清单哈希与运行时路径边界。

## 10. 非目标

第一版不包含：

- 三维树木、草丛、建筑、城堡或道路模型。
- 动态季节、积雪扩张、洪水、干旱或昼夜光照。
- 浏览器实时 PBR、Normal/Properties 材质采样。
- 对 AGOT 或 CK3 源目录的运行时监视。
- 远景与近景底图的半透明交叉渐变。
- 男爵领公开显示或向 LLM 暴露内部地点层级。

# 项目闭环与运行时完整性设计

日期：2026-08-21
状态：已实现并纳入当前架构（2026-08-21）

## 1. 背景

项目已经具备正文、人物、地图、资产、时间线、旅行与 LLM 双阶段结算，但当前产品体验仍存在明显割裂。问题并非缺少功能，而是若干关键边界尚未收束：存档只写不恢复、模型提供商名称与实际协议不一致、地图故障会穿透到正文回合、秘密事件缺少统一可见性过滤、界面暴露内部命令语言、资产分类依赖个别黑名单、地图生成验证未全绿、首屏与仓库负载偏重、README 与实际实现不一致。

本设计以“闭环、诚实、可验证”为目标，不新增玩法，不重做视觉风格。

## 2. 目标

1. 页面启动时恢复最近一份有效存档；导入存档后立即进入导入世界。
2. 不兼容或损坏存档不得静默覆盖，必须让用户明确选择重置。
3. 设置页只展示真正支持的模型协议；OpenAI-compatible 与 Anthropic 使用独立适配器。
4. 模型请求具备超时与取消能力，界面能表达解析、结算、叙事三个阶段。
5. 地图资料不可用时，普通正文回合仍能完成；只有明确依赖地图的动作被拒绝并解释原因。
6. 所有正文、人物卷宗、时间线与地图入口统一经过世界事件可见性选择器。
7. 正文不再显示内部命令名或“查看人物/地点/资产”占位文字，直接显示准确名称。
8. 资产分类由显式类别决定；政治制度或象征不进入普通资产系统。
9. 修复 DEM 海面扁平化回归，使完整验证恢复绿色。
10. 增加真实组件/交互测试，覆盖恢复存档、导入存档、抽屉导航与地图故障降级。
11. 降低首屏代码体积，并清理误提交的试验模型；不删除运行时必需资源。
12. README 和当前架构文档必须描述实际 schema、五级头衔和统一交互。

## 3. 非目标

- 不新增战斗、军队、经济或封臣玩法。
- 不继续扩展 3D 地标数量、材质或光照效果。
- 不迁移旧于当前测试版格式的存档；只提供明确错误和重置路径。
- 不删除 AGOT 原始导入记录中的铁王座；仅保证它不会被投影为普通资产。
- 不把 API Key 上传到服务端；当前仍是本地客户端工具，但必须明确安全边界。

## 4. 核心架构

### 4.1 启动恢复

新增独立的启动加载函数，从 IndexedDB 读取最近快照并执行完整 schema 与一致性验证。应用在恢复完成前显示启动状态；不存在快照时使用当前默认开局；不兼容快照进入可恢复错误态，不得自动清空。

Store 提供 `hydrateGameState()` 与 `replaceGameState()`。导入函数返回导入后的状态并直接调用 `replaceGameState()`，不依赖页面刷新。

### 4.2 模型提供商适配

新增 provider adapter 边界：

- `openai-compatible`：OpenAI、DeepSeek、SiliconFlow 和自定义兼容端点。
- `anthropic`：Anthropic Messages API，使用 `x-api-key`、`anthropic-version` 和 `/messages`。

解析阶段和叙事阶段都通过同一 adapter 选择器。每次请求使用统一超时控制器；用户可取消当前回合。取消或失败不得提交任何世界变化。

### 4.3 地图降级

把地图索引读取分成：

- 核心叙事可选上下文：失败时返回空人物/地点补充，不阻断普通行动。
- 地图强依赖意图：旅行、抵达、明确地点变更需要地图索引；不可用时只拒绝对应意图。

`prepareWorldTurn` 接受可选的预加载地图数据或“地图不可用”状态，不因无地图意图而强制读取地图。

### 4.4 可见性

新增统一选择器：

```ts
selectVisibleWorldEvents(events, viewer): WorldEvent[]
```

默认玩家视角只能看到 `public`，以及明确授权给玩家的事件。正文事实、人物经历、时间线和地图政治投影都使用该入口。世界事件数据模型扩展为可选 `knownBy`，为后续受限情报保留能力。

### 4.5 玩家可见命名

新增统一显示解析器，输出人物、地点、头衔和资产的名称。正文事实链接以名称为按钮文本；无法解析时显示事件摘要中的自然语言，不显示内部 ID 或命令枚举。技术审计信息放入折叠详情。

### 4.6 资产分类

世界神器记录增加显式投影类别：

```ts
type WorldArtifactProjectionKind = 'portable-asset' | 'political-symbol'
```

导入生成数据为铁王座标记 `political-symbol`。普通资产投影只接受 `portable-asset`。运行时保留基于 ID 的兼容保护，但不再作为主要分类依据。

### 4.7 测试与发布边界

- 保留现有 Node/Python 规则测试。
- 增加 Vitest、Testing Library 和 jsdom，验证组件实际渲染与点击行为。
- 修复 DEM 在重采样后水面重新出现高度差的问题。
- 把大型静态目录改为按需加载；至少将时间线、物品定义和重量级弹窗从首屏主包移出。
- 删除被 Git 跟踪的 `tmp/agot-model-pilot-*` 重复试验产物。

## 5. 验收标准

1. 创建两回合存档后重载应用，回合、日期、人物、世界状态保持一致。
2. 导入存档无需刷新即可显示导入状态；刷新后仍保持。
3. 损坏/旧格式存档不会被自动删除。
4. OpenAI-compatible 与 Anthropic 请求 URL、请求头、请求体和流式解析各自正确。
5. 模型请求超时或取消后，世界状态、队列和存档均不前进。
6. 地图清单或语义文件加载失败时，非地点行动仍能完成；旅行请求明确失败。
7. `secret` 世界事件不会出现在正文、人物经历、时间线或政治地图。
8. 正文事实按钮显示准确实体名称，不显示通用“查看…”文本或内部命令枚举。
9. 铁王座由显式 `political-symbol` 分类排除，其他普通神器不受影响。
10. `npm run verify`、类型检查和生产构建全部通过。
11. 至少四条真实 DOM 交互测试覆盖关键闭环。
12. README 与实际地图 schema version 4、五级头衔和当前交互一致。

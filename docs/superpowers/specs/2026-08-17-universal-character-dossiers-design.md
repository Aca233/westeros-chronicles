# 全角色 CK3 人物栏设计

## 目标

将当前只绑定玩家领主的 CK3 风格人物栏改成可展示任意稳定 AGOT 人物 ID 的通用人物栏。玩家保留健康、装备、仓储和随身物品操作；NPC 展示静态人物档案叠加当前存档动态事件后的资料，缺失内容不虚构。

## 架构

- `characterDossier.ts` 负责把玩家 `LordProfile` 或 NPC `ResolvedCharacter` 转换为统一的只读人物栏视图模型。
- `useCharacterDossier.ts` 按人物 ID 懒加载静态分片、读取当前 run 的 Dexie 事件并投影属性、特质、关系、伤势、头衔与记忆。
- `Ck3CharacterWindow` 接收当前人物选择、返回栈和选择回调。玩家模式复用现有 `CharacterSheet`、物品及历史；NPC 模式使用同版式的只读健康、经历与物品空状态。
- `App` 持有人物导航状态。桌面右栏和移动抽屉共享同一选择。回到自己会清空人物栈。
- 关系人物卡可继续打开对应人物；关系页提供按姓名检索稳定 AGOT 人物档案的入口。

## 数据规则

- NPC 年龄由当前年份与出生日期计算；数据年份兼容 `8298` 与界面显示的 `298 AC`。
- 缺失能力由现有确定性属性生成器补全，随后叠加正式特质修正；教育特质固定第一位。
- 家族、文化、信仰、位置和头衔只显示数据或动态事件能够证明的内容。
- NPC 不读取或复用玩家装备、金钱、威仪、恶名、仓储及随身物品。
- 动态死亡、伤势、移动、婚姻、离婚、头衔与记忆优先于静态档案。
- 不加入此前明确暂缓的右侧交谈、谋划、赠礼、婚姻、任命操作区，也不新增头衔与宣称页签。

## 交互与错误状态

- 加载 NPC 时保留人物栏骨架并显示核对档案状态。
- ID 不存在、分片读取失败或事件库失败时显示可关闭错误，不把人物栏切回错误人物。
- 点击关系卡或检索结果进入该人物；“返回”回到上一人物；“回到自己”清空栈。
- 已故人物在身份区和肖像区明确标记。

## 验证

- 单元测试覆盖 NPC 视图模型、年龄、教育特质顺序、动态伤势/头衔/婚姻投影与玩家物品隔离。
- 静态检查覆盖人物栏 props、关系卡入口、检索入口和导航入口。
- 运行 `npm run verify` 与生产构建。

# CK3 式近景三维地形设计

## 目标

在现有离线二维语义地图上增加 CK3 式近景地形起伏和镜头倾斜，同时保持战略区域、公国、伯爵领、政治投影、人物、资产、旅行路线与地点选择继续使用同一个 MapLibre 实例和同一份权威世界状态。

本阶段只交付三维地表与镜头交互，不生成城堡、城市、树木、军队、船只、云层或天气模型。远景仍是清晰、低负担的二维战略地图；近景三维层是可关闭、可失败回退的视觉增强，而不是新的地图模式或第二套世界坐标系统。

## 已确认的体验

1. 地图默认按缩放级别自动从二维俯视过渡到近景三维。
2. 玩家可使用“锁定俯视”关闭自动三维，设置在当前应用会话内保留。
3. 地图默认朝北；近景允许右键拖动和触屏双指旋转。
4. 关闭地图再打开时保留中心和缩放，但不保留旋转角度，重新朝北。
5. 工具栏提供归北控制，恢复朝北和当前缩放级别的推荐倾角。
6. 所有地图模式共用三维地表；地形模式最明显，政治模式适中，人物、旅行和资产模式更弱。
7. 地形不受支持或加载失败时继续显示完整二维地图，不把地图抽屉升级为初始化失败。

## 实现路线

采用 MapLibre GL JS 原生 `raster-dem` terrain。项目已经生成本地 Terrain-RGB DEM，并在样式中注册 `agot-dem` 数据源用于 hillshade；运行时只需在近景阈值内启用原生 terrain，无需增加 Three.js、第二个 WebGL 画布或新的坐标转换。

不采用自建 Three.js 网格，原因是它会迫使边界、标签、路线、地点点击和政治填色跨两个渲染器同步。也不采用纯阴影视差，因为倾斜镜头下无法产生真实山体轮廓。

## 地形数据与离线边界

- 高程源继续使用 `manifest.paths.dem` 指向的项目内 Terrain-RGB PNG 瓦片。
- 运行时不得读取 `/mnt/c/agot/2962333032`、Steam、Workshop 或网络资源。
- 原始 `9216×6144` 地图像素坐标仍是旅行、地点和世界逻辑坐标。
- MapLibre 伪经纬度只负责显示；开启地形不得改变地点 ID、路线距离或政治归属计算。
- 第一批不重新生成更高精度 DEM。若现有高度映射在视觉验收中暴露明显失真，只调整开发期 DEM 的高程标定参数并完整重建本地瓦片，不在浏览器内修补高度。

## 镜头状态模型

新增纯函数地形镜头配置模块，根据以下输入产生推荐状态：

- 当前连续 zoom。
- 当前 `MapMode`。
- 是否锁定俯视。
- 是否启用减少动态效果。
- 当前设备是否仍允许三维地形。

输出至少包含：

- `terrainEnabled`
- `pitch`
- `maxPitch`
- `terrainExaggeration`
- `rotationEnabled`

### 缩放阈值

- `zoom < 3.2`：推荐倾角为 `0°`，地形关闭。
- `zoom 3.2–4.8`：使用平滑插值逐渐增加倾角。
- `zoom >= 4.8`：达到当前模式的推荐最大倾角。

地形启用与关闭使用小范围迟滞，避免滚轮停在阈值附近时反复创建和销毁 terrain：进入近景约在 `3.25` 启用，缩回约在 `3.05` 关闭。语义层仍使用原有连续 zoom 权重，迟滞只影响原生地形资源。

### 各模式推荐最大倾角

| 模式 | 最大推荐倾角 | 目的 |
| --- | ---: | --- |
| 地形 | `52°` | 强调山脉、河谷和海岸轮廓 |
| 政治 | `42°` | 保留起伏，同时保证领地颜色和边界可读 |
| 人物 | `34°` | 优先保证人物聚合与人物图标清晰 |
| 旅行 | `34°` | 优先保证路线、途经点和当前位置清晰 |
| 资产 | `34°` | 优先保证据点与运输工具图标清晰 |

MapLibre 的硬上限设为 `55°`。玩家手动调整后的倾角不在每一帧强制覆盖；只有自动缩放过渡、地图模式切换、搜索飞行、解除俯视锁定或点击归北时应用推荐倾角。

### 地形强度

地形夸张系数保持克制，避免现有 16 位高度图把平原抬成尖峰：

- 地形模式：约 `0.9`。
- 政治模式：约 `0.78`。
- 人物、旅行、资产模式：约 `0.65`。

模式切换只更新 terrain 强度与推荐镜头，不创建第二份 DEM source。具体常量由纯函数集中管理，不能散落在 React 组件和样式文件中。

## 自动过渡与手动控制

### 自动过渡

- 连续缩放期间只计算轻量镜头目标，不重建政治、人物或资产 GeoJSON。
- 镜头更新以 `requestAnimationFrame` 合并，同一帧最多写入一次 pitch 或 terrain 状态。
- 启用减少动态效果时不播放长时间动画；缩放结束后直接采用目标倾角。
- 搜索地点和选择伯爵领仍飞往约 `zoom 4.8`，并在同一次镜头动画中采用对应模式的推荐倾角。
- 双击进入下一语义层时同时计算目标 zoom 和目标 pitch，不先放大再突然倾斜。

### 手动旋转

- 默认 bearing 为 `0°`。
- 近景且未锁定俯视时启用 MapLibre 右键拖动旋转、触屏双指旋转和触屏倾斜。
- 远景或锁定俯视时禁用旋转并平滑恢复 `pitch: 0`、`bearing: 0`。
- 键盘旋转保持关闭，避免与正文快捷键和无障碍导航冲突。

### 归北

归北控制执行一次镜头命令：

- `bearing` 回到 `0°`。
- `pitch` 回到当前 zoom 和模式对应的推荐值。
- center 与 zoom 不变。
- 减少动态效果开启时立即完成，否则使用短动画。

## UI 与状态

### 地图状态

`mapUiStore` 增加会话级 `topDownLocked` 和切换动作。它不进入游戏存档，也不改变现有存档版本。关闭地图抽屉不会清除它，页面重新载入后恢复默认自动地形。

归北是一次性镜头命令，不保存 bearing。可使用单调递增的请求编号从工具栏传到 `MapCanvas`，组件处理后不把 bearing 写回 Zustand。

`MapViewport` 继续只保存经度、纬度和 zoom。pitch 由 zoom、模式和俯视锁定推导，bearing 在新建地图时固定从零开始，因此不会把镜头视觉状态错误地变成世界状态。

### 地图工具栏

在现有模式标签附近增加两个紧凑按钮：

- “锁定俯视”：具有明确按下状态和 `aria-pressed`，再次点击恢复自动地形。
- “归北”：无持久按下状态，点击执行归北命令。

优先从 CK3/AGOT 本地游戏资源导入罗盘、山地或地图控制图标；没有适合且在小尺寸下清晰的游戏资源时，才使用高质量图标库。不得使用 Emoji、现代高楼、现代地图针或与中世纪世界观冲突的图形。

若三维地形在当前设备被禁用，“锁定俯视”呈不可用状态并通过可访问文本说明当前使用二维地图，不增加长期占据画面的警告横条。

## 图层与模式表现

- `agot-terrain` 栅格底图继续作为地表纹理。
- `agot-dem` 同时服务 hillshade 和原生 terrain，不复制 source。
- 战略区域、公国、伯爵领边界继续由现有语义瓦片绘制。
- 政治模式的填色保持半透明；必要时只按模式调整透明度和 hillshade 强度，不改变政治投影结果。
- 选中伯爵领轮廓、内部地点、人物、资产、路线和旅程进度继续使用现有图层，依靠 MapLibre 原生 terrain 贴地。
- 地点详情、旅行规划器和人物卷宗入口不因三维地形改变数据来源。
- 海域保持平面，不显示负高程形成的深坑；如 MapLibre 对现有 DEM 海面处理异常，开发期生成器把海域基准归一为零高程。

## 运行时生命周期

1. 地图仍先以完整二维样式初始化。
2. `load` 后确认 `agot-dem` source 存在，再创建地形控制器。
3. 控制器根据初始 zoom、模式和俯视锁定决定是否调用 `setTerrain`。
4. zoom、模式和锁定状态变化只通过控制器更新镜头与 terrain。
5. 地图关闭时取消动画帧、解除监听、停止地形更新，然后按现有流程 `stop()` 和 `remove()`。
6. 重新打开地图时使用保存的 center 与 zoom、bearing `0°`，再由控制器推导 pitch。

地形控制器与语义图层、政治投影、动态人物资产刷新保持独立。它不能在连续 zoom 事件中调用 `syncDynamicMapSubjects`、`syncPoliticalHouseLabels` 或重新加载语义索引。

## 故障隔离与二维回退

以下情况进入本次地图实例的二维回退：

- `setTerrain` 抛出异常。
- `agot-dem` source 不存在或不是 `raster-dem`。
- DEM 图块持续解码失败且错误可明确归因于地形 source。
- 浏览器或显卡不支持所需 terrain 能力。

回退流程：

1. 捕获错误并停止地形控制器继续尝试。
2. 安全调用 `setTerrain(null)`；若该调用也失败则忽略，不销毁地图。
3. 将 pitch 和 bearing 恢复为零。
4. 禁用本次实例的旋转和触屏倾斜。
5. 保留栅格底图、hillshade、政治、人物、资产、旅行和伯爵领交互。
6. 只显示一次非阻断说明“当前使用二维地图”，不得设置 `initializationError`，不得关闭地图抽屉。

普通缺失瓦片仍遵循现有局部错误策略。只有能归因于 DEM 或 terrain 的错误才触发三维回退，不能把任意矢量瓦片 404 误判为地形能力失败。

## 性能约束

- 远景不得为了三维额外预取超出既有 hillshade 所需级别的 DEM，也不得保持无用 terrain 网格。
- 同一帧最多执行一次自动镜头状态写入。
- terrain 启停必须使用迟滞，不能随阈值附近的滚轮抖动反复切换。
- 模式切换复用 source 和 map 实例。
- 视觉过渡不得触发人物、资产或政治全量重投影。
- 继续保持 MapLibre 只在地图抽屉打开时存在。
- 三维失败后的同一地图实例不自动重试；用户重新打开或点击现有“重新载入地图”后才重新探测。

## 可访问性与移动端

- “锁定俯视”使用 `aria-pressed` 表达状态。
- “归北”具有明确中文 `aria-label`。
- 减少动态效果模式取消长飞行和连续倾斜动画。
- 触屏双指旋转和倾斜不得阻断双指缩放。
- 单指拖动继续平移地图，避免移动端误旋转。
- 二维回退后控制按钮仍能通过键盘聚焦并说明不可用原因。

## 测试策略

### 纯逻辑测试

新增地形配置测试，覆盖：

- 三个缩放区间的推荐 pitch。
- 五种地图模式的最大倾角和地形强度。
- 锁定俯视强制 pitch、bearing 和 terrain 关闭。
- terrain 不可用时强制二维。
- 迟滞在阈值附近不反复启停。
- 减少动态效果只改变动画策略，不改变最终镜头状态。

### 运行时边界测试

- 样式继续只有一个本地 `agot-dem` source，且没有网络 URL。
- 地形控制器只在 style load 后运行。
- terrain 初始化失败不会设置地图初始化错误。
- 回退后政治、人物、资产、旅行和伯爵领图层仍存在。
- zoom 监听不重建动态 GeoJSON。
- 关闭地图时移除 zoom、rotate、pitch 和动画帧监听。
- 重新打开地图使用保存的 center 与 zoom，但 bearing 为零。

### 交互测试

- 搜索临冬城后达到近景并采用当前模式推荐倾角。
- 双击进入下一语义层时 zoom 与 pitch 同步变化。
- 锁定俯视后缩放不再自动倾斜。
- 解除锁定后恢复当前 zoom 推荐倾角。
- 旋转后点击归北只改变 bearing 和 pitch，不改变选中地点。

### 视觉验收

- 谷地和明月山脉有清晰但不过度的山势。
- 临冬城周边平原不会形成异常尖峰。
- 多恩山地与沙漠过渡自然。
- 君临和河湾地的政治填色、边界和中文文字仍清晰。
- 地点图标、人物、资产和旅行路线不埋入地表或被山体遮挡到无法操作。
- 模拟 terrain 失败时无缝维持二维地图。

## 验收标准

1. 远景仍是朝北的二维战略地图，近景按 zoom 自动进入三维。
2. 五种模式不重建地图实例，且按设计使用不同推荐倾角和地形强度。
3. 玩家能锁定俯视、旋转近景并一键归北。
4. 关闭重开后保留中心和 zoom，但 bearing 恢复为零。
5. 所有公开语义层、地点、人物、资产和路线仍使用现有权威数据。
6. 三维失败不会使地图画布初始化失败，并可继续完成二维地图全部交互。
7. 运行时完全离线，不读取模组目录，不向 LLM 暴露男爵领内部键。
8. 地图专项验证、类型检查和生产构建通过。

## 后续边界

后续若增加城堡、聚落、树林或军队模型，只能作为近景表现层消费现有地点、伯爵领和人物投影。模型层不得接管点击权威、旅行路径、政治状态或时间线，也不得要求正文模型理解新的空间键。

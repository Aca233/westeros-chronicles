# CK3 式地图语义缩放设计

日期：2026-08-19
状态：已确认；2026-08-19 修订为伯爵领最小可见层级

## 1. 背景

现有维斯特洛地图使用 MapLibre GL，缩放范围为 0–6。地点会按重要度逐步显示，道路和边界也有基础 `minzoom`，但缩放只改变镜头比例，没有像 CK3 那样改变地图表达层级。远景、中景和近景仍共享同一套省份、地点和圆点语义，因此远景容易显得零散，近景又缺少领地层级感。

本设计在保持五种地图模式、离线运行、统一政治时间线和现有旅行系统不变的前提下，实现 CK3 式连续镜头手感与语义缩放。三维地形不属于本轮范围，但新接口必须允许后续只替换近景地形层。

## 2. 目标

1. 缩放时依次呈现战略区域、公国和伯爵领层级；伯爵领是最小可见行政层级。
2. 层级之间连续交叉淡入淡出，不发生临界点闪烁或硬切换。
3. 滚轮、触控板、双击和触屏缩放具有接近 CK3 的连续镜头手感。
4. 保留玩家当前选择的地形、政治、人物、旅行或资产模式，不由缩放自动切换模式。
5. 政治模式远景以领地名称为主标签，以当前公开统治家族为副标签。
6. 人物和资产在中景聚合、近景展开，不把大量点位铺满远景。
7. 所有地图资料继续离线运行，不读取本机模组目录、Steam Workshop 或网络地图服务。
8. 保持正文、人物卷宗、政治时间线、统一回合和旅行队列的现有权威状态。
9. 为后续三维地形保留稳定的相机与语义层接口。
10. LLM 只接收具体地点、伯爵领、公国和战略区域的中文层级，不接收 `baronyId` 或男爵领概念。

## 3. 非目标

1. 本轮不生成三维网格、建筑模型或可倾斜地形。
2. 不实现军队、战争迷雾、建设或补给等新地图玩法。
3. 不允许缩放自动改变地图模式。
4. 不从远程服务下载字体、图块、边界或地名。
5. 测试版不兼容旧地图生成数据；旧清单将被新版 schema 明确拒绝。
6. 不改动现有存档中的人物、物品、政治和旅行权威结构。
7. 不生成或显示男爵领语义边界、标题、瓦片或缩放阶段；`baronyId` 仅保留为内部地点兼容键。

## 4. 总体架构

系统分为三个独立单元：

### 4.1 离线语义地图生成器

开发期导入器负责读取 AGOT 男爵领内部归属、伯爵领、公国层级和维斯特洛战略区域，将省份几何离线聚合为战略区域、公国和伯爵领三级可见语义边界，并计算标签视觉中心。男爵领只作为地点与省份的内部稳定键，不生成可见边界、标签、瓦片或缩放阶段。最远层使用“北境、河间地、多恩”等现有地理区域，而不是直接使用 AGOT 内部 `k_` 头衔；后者数量和含义并不等同于玩家理解的七国。输出只写入项目内生成目录。

生成器扩展现有地图清单并新增语义矢量瓦片：

- `/assets/agot-map/semantic/{z}/{x}/{y}.pbf`
- `/data/agot-map/semantic/titles.json`
- `/data/agot-map/semantic/membership.json`

语义瓦片包含以下 source layer：

- `realm_boundaries`
- `duchy_boundaries`
- `county_boundaries`
- `title_labels`

边界要素属性至少包含：

- `featureId`：按稳定头衔 ID 排序分配的确定性整数
- `titleId`
- `rank`
- `name`
- `regionId`
- `politicalAnchorTitleId`：仅战略区域可选，用于关联其公开政治头衔

标签要素除上述字段外，还包含视觉中心坐标和标签重要度。显示标签必须具有中文本地化；缺少中文本地化的头衔保留边界但不生成可见英文标签，并在导入报告中记录。

`titles.json` 保存三级可见标签的 feature ID、层级、中文名和视觉中心。`membership.json` 保存地点的内部 `baronyId` 兼容键以及伯爵领、公国和战略区域稳定映射，供人物、资产和政治标签聚合使用；运行时不得把 `baronyId` 解释为可见语义层。

### 4.2 运行时语义缩放控制器

新增纯逻辑模块，将连续 MapLibre zoom 转换为图层透明度、线宽、字号和交互密度。控制器不保存地图模式，也不保存政治状态，只根据当前 zoom 返回渲染参数。

语义控制器对外提供：

- 当前主要层级
- 相邻层级混合权重
- 各层边界透明度
- 各层标签透明度和字号
- 道路、地点、人物和资产的显示密度
- 双击时的下一个语义 zoom 目标

MapCanvas 只消费这些结果并同步 MapLibre 图层。MapUiStore 继续保存当前地图模式和视野；缩放不会改写 `mapMode`。

### 4.3 CK3 式相机配置

新增相机配置模块，集中管理滚轮、触控板、触屏、双击和程序化定位：

- 保持 MapLibre 原生鼠标锚点缩放。
- `zoomSnap` 设为 0，允许连续 zoom。
- 滚轮采用较低单次速率，初始 wheel rate 为 `1 / 600`。
- 触控板连续缩放初始 rate 为 `1 / 160`。
- 快速连续输入允许适度累积，但在停止输入后短暂缓停。
- 禁用 MapLibre 默认双击缩放，由自定义处理器把双击推进到下一个语义层的主观察点，不直接放到最大级别。
- 搜索结果仍可直接飞到伯爵领近景中的具体地点。
- 相机始终限制在维斯特洛裁剪边界内。
- `prefers-reduced-motion: reduce` 时取消额外惯性和长距离动画，保留即时定位。

具体速率在桌面鼠标和触控板验收中允许小幅校准，但不得改变语义层阈值或交互含义。

## 5. 语义缩放层级

缩放继续使用 0–6，并采用三级可见语义层与两个行政层交叉区间：

| zoom 区间 | 主要层级 | 主要内容 |
| --- | --- | --- |
| 0–1.4 | 战略区域远景 | 大领地轮廓、大字号领地名称、核心首府 |
| 1.1–2.8 | 公国中景 | 公国边界与名称、主要城堡、港口、主干道 |
| 2.5–6 | 伯爵领近景 | 伯爵领边界、城镇、道路、路线情报、人物、资产、旅程位置和地点详情 |

重叠区使用线性或平滑插值，不用布尔阈值突然切换。主要规则如下：

- 战略领地标签在 1.1 后逐步淡出，而非立即消失。
- 公国边界和标签在 1.1–1.4 淡入，在 2.5–2.8 淡出。
- 伯爵领在 2.5–2.8 淡入，并保持到最大 zoom。
- `4.1–4.4` 只用于人物、资产、道路和地点由聚合表达过渡到详细表达，不引入新的行政层。
- 同级标签通过 MapLibre collision 规则避让，首府和高重要度地点优先。
- 模式相关标签优先于一般地点标签。

## 6. 五种地图模式

### 6.1 地形模式

- 远景突出海陆、山脉和大区域名称。
- 中景增加山地、森林、河流和主干道。
- 近景显示全部道路和地点。
- 不使用强政治填色覆盖地形。

### 6.2 政治模式

- 所有 zoom 继续显示当前日期投影得到的政治颜色。
- 远景隐藏省份内部细线，只显示大领地轮廓。
- 中景依次增加公国和伯爵领边界。
- 近景继续显示伯爵领边界，并增加具体地点和道路细节；不显示男爵领边界或名称。
- 主标签显示领地中文名。
- 副标签显示当前公开统治家族。

政治副标签的解析顺序固定为：

1. 当前日期下该头衔的直接公开持有人之家族。
2. 若没有直接持有人，则统计下属省份公开政治状态，选择覆盖省份数最多的家族。
3. 数量相同时按稳定家族 ID 排序，保证结果确定。
4. 没有公开信息时不显示副标签，不用秘密或当前真值补齐。

政治状态仍由现有 worldHistory 和人物头衔投影产生；语义地图不保存第二份当前领主状态。

### 6.3 人物模式

- 0–2.5 不显示大量人物点。
- 2.5–4.1 按伯爵领或当前可用的最近语义层聚合，显示人数。
- 4.1–6 展开为单独人物点。
- 已故人物、未知位置、无权威地点或不可见情报继续隐藏。
- 点击单独人物仍打开同一人物卷宗并关闭地图抽屉。

### 6.4 旅行模式

- 当前路线总览和旅程位置在所有 zoom 可见。
- 远景显示整条路线和主要途经区域。
- 中景显示主干道、海路和途经点。
- 近景显示具体路段、地点和当前位置。
- 缩放不重算、不改变也不取消已规划路线。
- 排队出发、改道、返回、暂停和取消仍按下一次成功对话结算规则执行。

### 6.5 资产模式

- 0–2.5 不显示大量资产点。
- 2.5–4.1 按伯爵领或地点聚合，显示据点与运输工具数量。
- 4.1–6 展开为单独据点和运输工具。
- 物品数量只来自统一物品状态，不从地图生成或猜测。

## 7. 标签与字体

静态领地标签使用 MapLibre symbol layer 和碰撞避让。运行时设置本地中文表意文字字体族，禁止请求网络 glyph。标签内容限定为导入器确认的中文字符串；若某头衔缺少中文本地化，则该标签不显示并进入导入报告。

领地名称和家族副标题使用两个独立 symbol layer，允许不同字号、颜色、透明度和碰撞优先级。静态主标题来自语义矢量瓦片；动态家族副标题来自只包含当前视野、当前语义层标签的轻量 GeoJSON source。副标题不与主标题拼成单一字符串，避免因政治变化重建静态瓦片。

## 8. 动态政治标签

语义标签要素使用确定性整数 `featureId`。运行时根据当前政治投影生成当前视野、当前语义层的副标题 GeoJSON，属性包括 `politicalHouseId`、`politicalHouseLabel` 和 `politicalHolderId`。只有 zoom 跨越语义层、视野移动结束或 `changedTitleIds` 影响当前可见领地时才调用 `setData`；静态主标题和边界不重建。

公国和伯爵领优先使用当前日期下的直接头衔持有人。战略区域先查可选的 `politicalAnchorTitleId`，没有锚点或直接持有人时再按区域内公开省份政治状态选择主要统治家族。历史日期重建、继承、死亡、授予、撤销和正式战争结果沿用现有政治折叠规则。秘密事件和未正式确认的战争结果不得进入标签。

## 9. 人物与资产聚合

聚合使用语义 membership，而不是随机空间网格：

- 中景人物按伯爵领聚合；缺少伯爵领时按公国聚合。
- 中景资产优先按具体地点聚合；密集地点再提升到伯爵领。
- 聚合点使用对应语义层的视觉中心。
- 聚合 ID 由模式、层级和稳定头衔 ID 构成，缩放和重载后保持稳定。
- 数量和成员列表按稳定 ID 排序，避免显示抖动。
- 进入 4.1–4.4 细节交叉区时，聚合点淡出、单点淡入；伯爵领边界和标题保持稳定。

现有像素视野裁剪继续生效，MapLibre 只接收当前视野需要的动态点。

### 9.1 LLM 地点上下文

统一回合上下文通过语义 membership 把当前权威地点解析为“具体地点、伯爵领、公国、战略区域”的中文链路。提示词不得包含 `baronyId`、`b_` 内部地点键、男爵领名称或男爵领头衔。若语义资料暂时不可用，只提供已经验证的具体地点中文名，不回退到内部 ID 或英文头衔。

LLM 不再直接输出 `CHANGE_LOCATION` 或依赖内部地点键移动人物。玩家旅行、改道、暂停、返回和取消继续由地图旅行系统、统一回合以及下一次成功对话结算；模型只能叙述已提交的权威位置和旅程状态，不能自行生成位置迁移。内部地点键仍可被状态归约器和旅行系统使用，但不进入模型消息。

## 10. 数据生成与原子性

导入过程固定为：

1. 读取省份几何和头衔层级。
2. 校验每个参与地图的省份只属于一个稳定内部男爵领键，并能解析到伯爵领。
3. 只按伯爵领、公国和战略区域执行可见几何 union。
4. 修复可安全修复的几何；无法修复时终止导入。
5. 计算位于聚合几何内部的标签视觉中心。
6. 解析中文本地化并记录缺失项。
7. 构建语义瓦片、标签索引和 membership。
8. 审计要素数量、层级引用、几何范围、feature ID 唯一性和瓦片可解码性。
9. 所有检查通过后原子替换旧输出。

真实 AGOT 导入仍只能由开发者显式执行，不进入 `verify` 或 `verify:quick`。

## 11. 清单与 schema

地图清单升级为新版本，并新增：

- `paths.semantic`
- `paths.semanticTitles`
- `paths.semanticMembership`
- 三级可见语义要素数量
- 中文可见标签数量
- 缺失本地化数量
- 语义数据哈希

运行时 schema 要求这些字段存在且只能指向 `/data/agot-map/` 或 `/assets/agot-map/`。旧清单、新旧文件混用、外部 URL、绝对路径、父目录跳转和非法来源标识均被拒绝。

## 12. 故障隔离

- 语义清单、索引或瓦片损坏时，地图抽屉显示明确错误和“重新载入地图”。
- MapErrorBoundary 继续只隔离地图画布子树。
- 正文、人物卷宗、回合提交和存档不受地图失败影响。
- 不回退到网络地图、本机 Workshop 或原 AGOT 目录。
- 动态政治副标签失败时可隐藏副标签，但不能显示未验证的替代值。
- 聚合失败时隐藏对应动态图层，不影响地形、政治和旅行路线。

## 13. 性能约束

- 静态语义边界和标签必须使用矢量瓦片，不把全部聚合几何作为单个 GeoJSON 加载。
- 只加载当前视野与当前 zoom 所需瓦片。
- zoom 过程使用样式表达式完成视觉插值，不在每一帧重建 React 状态。
- 省份政治填色的 feature-state 只更新变化头衔；政治副标题只重建受影响的当前视野数据。
- 人物和资产在 `moveend` 或语义层实际变化时重新聚合，不在连续滚轮事件每帧计算。
- 地图抽屉关闭时继续停止并销毁 MapLibre 实例。
- 不新增运行时网络依赖。

## 14. 可访问性与输入

- 地图模式按钮、搜索和详情保留键盘操作。
- 双击缩放不替代现有单击地点选择。
- 触屏双指缩放保持可用，禁止旋转以保持二维地图方向稳定。
- `prefers-reduced-motion` 下取消长时间飞行和额外惯性。
- 标签和聚合标记保持足够对比度，不能只依靠颜色区分模式。
- 不使用 Emoji。

## 15. 测试策略

### 15.1 导入器测试

- fixture 生成三级可见聚合几何、标签和带内部 `baronyId` 的 membership。
- 反向输入顺序输出完全一致。
- 循环或悬空头衔引用被拒绝。
- 聚合几何越界、空几何和重复 feature ID 被拒绝。
- 标签视觉中心位于对应几何内部。
- 缺少中文本地化不会产生英文可见标签，并进入报告。
- 写入失败时保留上一份有效输出。

### 15.2 运行时纯逻辑测试

- zoom 到三级权重映射及两个行政层重叠区插值。
- 双击返回下一个语义 zoom 目标。
- 五种模式在 zoom 变化后保持不变。
- 人物和资产聚合稳定、去重且遵守情报可见性。
- 政治主标签和家族副标签按规定解析。
- 历史日期变化只更新受影响头衔。
- 减少动态效果配置关闭额外动画。
- LLM 地点上下文不含 `baronyId`、`b_` 内部键或男爵领概念，并禁止模型直接输出位置迁移。

### 15.3 MapLibre 集成检查

- 新 source layer、symbol layer 和边界层全部存在。
- 图层 minzoom、maxzoom、opacity、字号和线宽表达式符合设计。
- 样式不包含网络 URL。
- 当前模式显隐规则覆盖所有新图层。
- 地图关闭后事件与实例被清理。

### 15.4 完整验证

- `npm run verify:map`
- `npm run build:code`
- 最终阶段运行一次 `npm run verify`
- 桌面与移动端分别检查远景、中景、近景截图。
- 鼠标滚轮、触控板、双击、搜索飞行和减少动态效果进行人工验收。

## 16. 验收标准

1. 从最大远景连续缩放到伯爵领近景时，用户能明显感知战略区域、公国、伯爵领三级表达；最大近景不会出现男爵领边界或名称。
2. 缩放过程中没有标签整体闪烁、边界硬跳或地图模式被重置。
3. 政治模式远景显示领地中文名和当前公开统治家族。
4. 人物与资产不会污染远景，中景可见聚合数量，近景可单独点击。
5. 旅行路线在全部缩放层保持连贯，已有旅行状态不被重算或修改。
6. 所有地图资源由项目内离线路径提供。
7. 地图失败不影响正文、人物卷宗和回合系统。

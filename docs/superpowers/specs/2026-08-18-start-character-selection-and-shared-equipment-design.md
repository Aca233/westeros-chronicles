# 现成人物开局与统一健康装备界面设计

## 目标

删除固定剧本预设入口，保留自建统治者，并允许玩家直接从项目内置 AGOT 人物数据中选择开局角色。玩家与 NPC 使用同一视觉结构的健康与装备面板，玩家可操作，NPC 只读。

## 开局人物

开局创建器包含“选择现成人物”和“自建统治者”两个页签。现成人物页顶部展示一组推荐角色，推荐项只是人物数据集记录的快捷入口，不复制属性。下方提供全人物搜索；仅允许选择开局时已出生、存活且非家谱层人物。选择后加载人物、头衔、装束配置和特质，转换为玩家 LordProfile 与 ItemSystemState，并使用统一 298 AC 开局日期。

## 健康与装备

玩家和 NPC 显示相同的四区伤势、人体常态描边、五组装备位置和装备卡片。玩家继续使用现有装备操作组件；NPC 使用相同版式的只读装备卡，不出现更换按钮。所有权、保管与实际穿戴仍严格区分。

## 约束

- 不使用 Emoji。
- 不在运行时读取 CK3 或 AGOT 原始文件。
- 推荐角色引用稳定人物 ID，不作为新预设保存第二份人物数据。
- 自建人物功能完整保留。
- 不考虑旧存档迁移。
- 不提交、不合并、不推送。

# 身体、健康、时间与装备运行时

## 权威状态

`GameState.health` 是人物健康的权威账本，按人物 ID 保存 `CharacterHealthState`。每个人物拥有惯用手、生存需求、最后更新时间和独立伤病列表。旧 `lord.body` 只作为兼容投影继续服务仍未迁移的四区显示/旧代码；新规则不得把它作为结算权威。

精确身体部位为：头、胸、腹、左/右臂、左/右手、左/右腿、左/右足。旧档无法确定侧别的记录迁移为 `unknown_torso`、`unknown_upper_limb`、`unknown_lower_limb`，绝不复制到左右两侧。

伤病记录包含原因、类型、严重度、出血、疼痛、感染、治疗状态、恢复阶段与可选永久后果。首版类型为割刺伤、挫伤、骨折、烧伤、疾病、中毒、永久残疾。

## 能力与伤势

`deriveHealthCapabilities` 从独立伤病推导左/右握持、双手协作、行走、奔跑、视力、听力和清醒程度。每条原因携带伤病 ID；调用方不得再按同一伤病手工叠加第二份难度惩罚。

手持槽仍保留历史持久化字段 `mainhand/offhand`，但规则层解释为“惯用手/非惯用手”，再由 `physicalHandForEquipmentPosition` 映射到真实左/右手。这样旧物品存档无需复制或改槽位 ID，同时新伤病规则可以准确阻止受伤/残缺手持物和双手武器。

## 命中、防护与耐久

`APPLY_HIT` 是新伤害入口。程序按精确命中部位、伤害标签、实际穿戴的覆盖效果和当前耐久计算一次防护，再生成实际伤病。一次攻击即使同一装备贡献多个防护效果，也只对该装备结算一次耐久损耗。

物品继续使用现有 D20、检定加值、防护、重量/负担、耐久和物品历史，不另建平行战斗属性体系。

## 治疗

`TREAT_INJURY` 必须引用真实 `injuryId`。处理分为：

- `first_aid`：急救/包扎，可控制出血，但不会直接降低伤势等级。
- `immobilize`：骨折固定；固定后仍然是骨折，也不会立即恢复行走能力。
- `definitive`：正式处理，为恢复创造条件，但不瞬间把重伤改成轻伤。

所有物资可达性、用途、治疗者、物品品质和环境先验证，验证通过之后才消耗物品。失败事务不扣医疗物资。

## 生存与时间

游戏时刻由日期加 `currentMinute` 组成。旧档只有日期时迁移为当天 12:00，并标记 `currentTimePrecision = day_only`，表示真实日内时刻未知，而不是伪造精确事实。

Resolution V2 的 `actionPhases` 负责给出行动阶段、分钟数、活动强度和耗时依据。正常睡眠只有 `rest` 阶段且 `sleep=true` 时成立。若 `actionPhases` 已表达耗时，通用 `ADVANCE_TIME/SET_DATE` 不会再重复推进。

饥饿、口渴和疲劳按实际经过分钟及活动增长。有食物/饮水且物品确实在随身、当前据点或当前位置载具中时，程序可自动消耗；不会自动购买、偷取或服药。断水、极端疲劳、清醒能力过低、严重失血或死亡会中断长行动。

旅行以同一分钟时钟推进。若健康/补给在计划耗时之前要求中断，路线会按实际走过的分钟重新计算部分进度，人物、同行者和载具位置回写到该中断点，不允许完整路线先抵达再只把状态标签改成 interrupted。

## NPC 与认知

玩家使用完整生存模拟。NPC 只在以下情况下按需推进：当前场景在场、被本回合健康命令明确作用、或已经有未愈持续伤病。NPC 不自动消耗离屏补给，也不进行全世界逐分钟模拟。

`visibleCharacterHealth` 是健康信息投影边界。NPC `hiddenFromPlayer=true` 的伤病在普通玩家视图中过滤；只有人物本人或 debug 视图可见。正文和面板不得绕过这一投影读取隐藏伤病。

## 存档

当前存档格式为 v11。v9 先按原有规则迁到 v10，再由 v10 迁到 v11。迁移在内存中产生新投影；数据库中的旧原始快照不会仅为了升级而被静默重写。旧伤病不复制，旧装备实例/位置/历史保持原样，迁移不会凭空新增死亡或残疾。

## 回合原子性

世界事务先验证但不推进时间，随后健康/生存按计划分钟在克隆状态上结算；只有完整回合成功后才由 `commitTurnAtomically` 写入存档。因此模型重试、事务拒绝、打开/关闭面板和读档不会额外推进时间或重复扣血、扣补给。

## 定向验收

运行：

```sh
npx tsx scripts/check-health-equipment-runtime.mjs
```

覆盖左右手/惯用手、双手协作、命中覆盖、防护单次结算、治疗原子性、骨折固定、赶路与睡眠疲劳、自动补给、断水中断、长/分段推进一致性、旧档未知侧迁移、隐藏 NPC 伤病过滤和明确致命头击。

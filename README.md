# 维斯特洛编年史

一个以 CK3 / AGOT 风格人物系统为基础的 AI 文字角色扮演前端。项目包含统治者设计器、人物特质与六项属性、人物关系资料、伤势与装备、随身物品、D20 检定以及场景人物状态系统。

## 当前功能

- CK3 风格通用人物窗口与统治者设计器
- 关系卡连续查看、返回人物与全 AGOT 人物姓名检索
- 外交、军事、管理、谋略、学识、勇武六项属性
- 教育、性格、先天、健康、生活方式和名望特质
- AGOT 人物资料、稳定人物 ID、关系档案与存档动态事件投影
- 身体伤势、日常装备、据点储藏和运输工具
- 装备在下一次成功对话后生效
- 可选 D20 行动检定和特质规则效果
- 人物事件、记忆与状态回滚

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

完整验证：

```bash
npm run verify
```

## 数据说明

`public/data/agot-characters` 包含项目运行所需的预处理人物数据。关系页可按姓名打开任意稳定人物档案；NPC 的身份、特质、属性、亲属、伤势、头衔和记忆会叠加当前存档事件，未记录的装备与物品保持未知，不会复制玩家物品。原始 AGOT Workshop 文件、音频资源、构建产物和本地分析缓存不会提交到仓库。

本项目仅用于个人开发与研究。CK3、AGOT 及相关素材的权利归各自权利方所有。
